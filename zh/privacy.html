隐私政策

生效日期：2026 年 10 月 24 日用户协议

目录

OpenBeast 是 macOS 上的一个笔记本 App。它没有账号，也不收集使用统计。本政策说明这个网站和 OpenBeast App 会通过网络发送什么、发给谁。

一、这个网站

  • 网站是静态页面，托管在 Vercel。和所有网站托管一样，Vercel 会保留常规的访问日志（如你的 IP 地址、浏览器和打开的页面），用来运行和保护服务。
  • 网站不设置 Cookie，不用任何统计或广告。
  • 为了显示最新版本号，你的浏览器会向 GitHub（api.github.com）查询。下载按钮会带你到 GitHub 上的安装包。

二、OpenBeast App

  • 不需要账号，没有使用统计、数据分析或崩溃上报。你的文档、App 和对话都留在你的 Mac 上。
  • App 只在这些时候联网：检查和下载更新（经 openbeast.app，文件来自 GitHub）；打开 App Store 页面时读取 App 清单和你安装的 App（每个安装包都会核对签名）；在设置里查看 AI 工具列表时，查询这些工具的最新版本，以及在你要求时下载公开的 AI 服务商列表。
  • 你自己发起的操作（例如从 GitHub 导入）会连到你指定的服务器。

三、AI

OpenBeast 不卖 AI，也不夹在你和 AI 中间。你装的 AI 工具用你自己的账号登录，你的请求从你的 Mac 直接发给它们的服务商，从不经过 OpenBeast 的服务器。你发给服务商的内容适用该服务商自己的隐私政策。

四、可选的手机功能

接入手机（「设置 → 手机」）是可选的。接入后，你的 Mac 会把你选择的内容（Todo 待办、文档、对话及其附件、你在手机上打开的 App 页面）同步到你注册的中转服务，由它保存，好让手机能用。该服务有自己的隐私政策和用户协议，注册前会给你看。

五、变更与联系

本政策有变化时，新版本和生效日期会显示在本页。有任何问题，请在 GitHub 上问我们。
